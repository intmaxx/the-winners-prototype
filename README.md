# The Winners Academy — clickable prototype

Static, clickable mockups of the staff app for 더 위너스학원, exported from the design canvas.
All names and numbers are sample data. This is not the application; the real code lives in a private repo.

- Start page: `Light.dc.html` (home). Use the left menu to move between screens.
- `?role=teacher` opens a page in the teacher view; the last choice of the view switch is remembered.
- `font.woff2` is Pretendard (SIL Open Font License 1.1).
